Comparisons & "AS" Expressions

How comparatives, superlatives and as...as structures work — and exactly how Cambridge tests them in the Use of English paper.

1. Comparative & Superlative Forms

A quick review before we build on it with as...as.

Adjective typeComparativeSuperlative
Short (1 syllable)tall → tallerthe tallest
Ending in -elarge → largerthe largest
Consonant + -yhappy → happierthe happiest
1 syllable, C-V-C (double letter)big → biggerthe biggest
Long (2+ syllables)expensive → more expensivethe most expensive
Irregulargood → better · bad → worse · far → furtherthe best / the worst / the furthest

Modifying comparatives

Big gap much / a lot / far + comparative This flat is far more expensive than the last one.
Small gap a bit / slightly / a little + comparative Today it's a bit colder than yesterday.
Common error: never use very before a comparative — "very bigger" is always wrong.

Trends & parallel increases

Repeated comparative comparative + and + comparative The traffic got worse and worse as rush hour approached.
Double comparative the + comparative..., the + comparative... The more you practise, the more confident you'll feel.

2. Equality — AS...AS

This is where most B2 students lose marks, so it's worth learning the patterns precisely.

Equal as + adjective + as She's as tall as her brother. (same height)
Not equal not as/so + adjective + as This film isn't as good as the first one. (the first one is better)
Note: so...as only appears in negative sentences. as...as works in both positive and negative.
Multiples number + times as + adjective + as This flat is twice as big as mine.
Maximum degree as + adjective + as possible Try to arrive as early as possible.
Identical the same (+ noun) + as My phone is the same brand as yours.

3. Other Key "AS" Expressions

Beyond as...as, "as" carries several other meanings that come up constantly at B2.

ExpressionMeaningExample
as soon asimmediately afterCall me as soon as you land.
as long asprovided that (condition)You can go out as long as you finish your homework.
as far asto the extent that / limitationAs far as I know, she's still in Madrid.
as well asin addition toHe plays the guitar as well as the piano.
as if / as thoughas if it were true (often unreal)She acted as if she hadn't heard me.
as (reason)because (more formal)As it was raining, we cancelled the trip.
as (time)while, at the same momentAs I was leaving, the phone rang.
so as toin order to (purpose)She whispered so as not to wake the baby.

4. How Cambridge Tests This

In B2 First Use of English, these structures turn up across three parts — here's exactly what to expect.

Part 1 · Multiple-choice cloze

One of the four options is often a similar "as" phrase, testing whether you know which one fits the meaning.

He's a talented footballer  ____  a good student.

A) as well as   B) such as   C) so as   D) as long as

Answer: A — as well as

Part 2 · Open cloze

The missing word is very often as itself, since it appears twice in most of these structures.

You can borrow the car  ____  long  ____  you fill up the tank.

Answer: as / as

Part 4 · Key word transformation

This is where comparatives and as...as appear most — usually by flipping a comparative sentence into its equal/unequal opposite.

Tom is more experienced than Sam. (AS)
Sam  ____________________  Tom.

Answer: isn't as experienced as
